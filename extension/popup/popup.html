연결 상태 확인 중…

1. 앱 연결

Windows 앱을 실행하고 트레이 아이콘을 우클릭해 페어링 코드를 복사하세요.

2. 번역 설정

DeepL 계정에서 발급한 개인 API 키를 입력하세요. 사용량은 본인 계정에 청구될 수 있습니다.

계정 연결을 확인해 주세요.

연결 버튼을 누르면 로그인 창이 열립니다. CLI가 없으면 공식 CLI를 먼저 설치합니다. 브라우저에서 로그인한 뒤 연결을 확인하고 설정을 저장하세요.

최신 공식 CLI와 이를 사용할 수 있는 계정·요금제가 필요합니다. 원문과 번역 맥락이 선택한 서비스로 전송되며 해당 CLI의 사용 한도가 적용됩니다. CLI 호출로 자막이 늦게 나올 수 있습니다.

3. 자막 보기

지원 사이트에서 영상이나 음성을 재생하세요. 번역 설정은 저장 후 다음 발화부터 적용됩니다.

4. 음성 자막 사이트

같은 주소를 다시 추가하면 자막 모드가 바뀝니다. 변경 후 해당 탭을 새로고침하세요.
